# WorkspaceZero fonts

Jost variable (weight 300 for display text) and Inter variable (UI text) are
self-hosted from the official Google Fonts repository. License texts accompany
the unmodified fonts as Jost-OFL.txt and Inter-OFL.txt.

Sources:
- https://github.com/google/fonts/tree/main/ofl/jost
- https://github.com/google/fonts/tree/main/ofl/inter

CSS uses font-display: swap. No Google requests or font downloads are needed at
build time or by visitors. No extra package dependency is required.
